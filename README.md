# 최후의 생존자 추첨

좀비 아포칼립스 테마의 교실용 랜덤 추첨 웹앱입니다. 설치 없이 브라우저에서 `index.html`을 열면 바로 쓸 수 있습니다.

## 모드

- **좀비 생존자 추첨**: 좀비 떼가 도망치는 학생들을 쫓습니다. 붙잡힌 학생은 좀비가 되어 추격에 합류하고, 끝까지 남은 1명이 구조 트럭에 오르는 최후의 생존자가 됩니다. 붙잡힌 순서의 역순으로 전체 순위가 정해집니다.
- **일반 순서 뽑기**: 학생이 한 명씩 구조 트럭에 올라탑니다. 탑승 순서가 발표 순서이며 중복은 없습니다.

## 기능

- 이름 한 명씩 입력 / 여러 명 한 번에 붙여넣기 (줄바꿈·쉼표·띄어쓰기 구분, 중복 제거)
- 카운트다운, 경보 사이렌, 효과음(Web Audio 합성), 결과 공개 연출
- 좀비 모드는 시작하면 끝까지 자동 진행, 남은 결과 한 번에 공개, 다시 뽑기, 전체 초기화, 결과 복사
- 스페이스바·Enter로 진행, 전체 화면, PC·태블릿 반응형
- 저사양 기기용 간소화 연출 옵션

## 공정성

추첨을 시작하는 순간 `crypto.getRandomValues` 기반의 편향 없는 난수로 피셔–예이츠 섞기를 한 번 실행해 전체 순서를 확정합니다. 화면 연출은 결과에 영향을 주지 않습니다.
