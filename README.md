# 최후의 생존자 추첨

고블린 숲 탈출 테마의 교실용 랜덤 추첨 웹앱입니다. 추격 장면은 3D(three.js)로 그려집니다. 설치 없이 브라우저에서 `index.html`을 열면 바로 쓸 수 있습니다.

**바로 실행:** https://jhkang20084-a11y.github.io/zombie-draw/

## 어떻게 진행되나요

- 학생들이 줄무늬 옷을 입은 친구들이 되어 숲길을 달리고, 고블린 무리가 일정한 속도로 뒤쫓습니다. 카메라는 고블린 무리 뒤쪽 위에서 따라갑니다.
- 친구들은 순위대로 거리를 두고 달립니다. 앞선 친구는 멀리 앞서 있고, 곧 잡힐 친구일수록 고블린 가까이에 있습니다.
- 달리는 동안 여러 사건이 자주 일어납니다.
  - 길 위의 빨간 버섯을 먹으면 잠깐 빨라집니다.
  - 돌을 폴짝 뛰어넘어 피하거나, 돌에 걸려 넘어집니다.
  - 지쳐서 느려지기도 합니다.
  - 앞 친구 머리를 밟고 튀어 나가기도 합니다. 밟힌 친구는 납작하게 눌렸다가 잠깐 멈춥니다.
  - 고블린 코앞까지 밀렸다가 아슬아슬하게 달아나기도 합니다.
- 넘어진 친구도 다시 일어나 달리지만, 계속 뒤처지면 고블린에게 붙잡혀 그 자리에 쓰러집니다.
- **붙잡힌 순서가 곧 발표 순서**이고, 끝까지 남은 1명은 구조 자동차 옆에서 계속 달아납니다.
- 오른쪽 위에 현재 순위가 나오고, 이름을 누르면 카메라가 그 친구를 따라갑니다. 따라가던 친구가 잡히면 가까이 비추고 이름을 크게 보여 줍니다.
- 시작 버튼을 한 번 누르면 끝까지 자동으로 진행됩니다. 무대 위 1x / 2x / 4x 버튼으로 빨리 감을 수 있습니다.
- 끝나면 아래 가운데의 "결과 보기"를 누르세요. 추격 장면 위에 반투명 창으로 발표 순서가 뜹니다.

## 기능

- 이름 한 명씩 입력 / 여러 명 한 번에 붙여넣기 (줄바꿈·쉼표·띄어쓰기 구분, 중복 제거)
- 화면을 꽉 채우는 추격 장면, 신나는 배경음악과 귀여운 효과음 (Web Audio 합성)
- 다시 뽑기, 전체 초기화, 결과 복사
- 소리 켜기·끄기, 전체 화면 (추격 장면 오른쪽 아래)
- 저사양 기기용 간소화 연출, PC·태블릿 반응형 (WebGL이 안 되는 기기에서는 2D 장면으로 자동 전환)

## 공정성

추첨을 시작하는 순간 `crypto.getRandomValues` 기반의 편향 없는 난수로 피셔–예이츠 섞기를 한 번 실행해 전체 순서를 확정합니다. 넘어지고, 버섯을 먹고, 밟히고, 붙잡히는 장면은 이미 정해진 순서를 보여 주는 연출일 뿐 결과에 영향을 주지 않습니다.
