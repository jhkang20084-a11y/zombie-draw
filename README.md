# 최후의 생존자 추첨

고블린 숲 탈출 테마의 교실용 랜덤 추첨 웹앱입니다. 설치 없이 브라우저에서 `index.html`을 열면 바로 쓸 수 있습니다.

**바로 실행:** https://jhkang20084-a11y.github.io/zombie-draw/

## 어떻게 진행되나요

- 학생들이 줄무늬 옷을 입은 친구들이 되어 숲길을 달리고, 고블린 무리가 일정한 속도로 뒤쫓습니다.
- 달리다 보면 돌에 걸리거나, 벌레에 부딪히거나, 지쳐서 느려지는 친구가 생깁니다. 다시 일어나 달리지만, 계속 뒤처지면 고블린에게 붙잡혀 그 자리에 쓰러집니다.
- 길 위의 빨간 버섯을 먹은 친구는 잠깐 빨라집니다.
- **붙잡힌 순서가 곧 발표 순서**이고, 끝까지 남은 1명이 최후의 생존자로 구조 자동차에 도착합니다.
- 시작 버튼을 한 번 누르면 끝까지 자동으로 진행됩니다.

## 기능

- 이름 한 명씩 입력 / 여러 명 한 번에 붙여넣기 (줄바꿈·쉼표·띄어쓰기 구분, 중복 제거)
- 카운트다운, 효과음(Web Audio 합성), 결과 공개 연출
- 남은 결과 한 번에 공개, 다시 뽑기, 전체 초기화, 결과 복사
- 생존자 현황·탈출 일지는 접어 두었다가 필요할 때 펼치기
- 연출 속도(빠르게·보통·천천히), 저사양 기기용 간소화 연출, 전체 화면, PC·태블릿 반응형

## 공정성

추첨을 시작하는 순간 `crypto.getRandomValues` 기반의 편향 없는 난수로 피셔–예이츠 섞기를 한 번 실행해 전체 순서를 확정합니다. 넘어지고, 버섯을 먹고, 붙잡히는 장면은 이미 정해진 순서를 보여 주는 연출일 뿐 결과에 영향을 주지 않습니다.
